# 우리 반 자리 뽑기 (Classroom Seat Picker) 🎲

교실에서 학생들의 자리를 무작위로 공정하고 재미있게 배치해 주는 반응형 웹 애플리케이션입니다.

## ✨ 주요 기능

- **4분단 × 6줄 (총 24석) 교실 레이아웃**:
  - 교탁과 칠판이 있는 앞쪽 기준 정렬
  - 분단별 색상 구분 및 통로/중앙 통로 표시
- **학생 수 맞춤 설정**:
  - 학생 수를 입력하면 1번부터 해당 번호까지만 랜덤 배치
  - 정원(24명)보다 적을 경우 남는 자리는 깔끔하게 '빈자리'로 처리
- **두근두근 롤링 애니메이션**:
  - 뽑는 순간 번호들이 빠르게 회전하는 슬롯 애니메이션으로 기대감 극대화
  - 순차 공개 모드: 앞줄부터 순서대로 긴장감 넘치게 자리 공개
  - Web Audio API 기반 오프라인 사운드 효과 (회전음, 오픈음, 축하 팡파르)
  - 완료 시 축하 색종이(Confetti) 폭죽 효과
- **다시 뽑기**:
  - 언제든지 원클릭으로 자리를 즉시 재배치
- **교실 최적화 편의 기능**:
  - 전자칠판/TV용 전체화면 모드 지원
  - 출력용 배치표 인쇄 지원 (A4 최적화)
  - 학생 이름 없이 순수 **번호**로만 표시
